# MySQL 쿼리 학습 가이드 개발 - 수락 기준

**@ACCEPTANCE:SQL-001**

## 개요 (OVERVIEW)

이 문서는 MySQL 쿼리 학습 가이드 개발의 완료 기준을 정의합니다. 모든 시나리오는 Given-When-Then 형식으로 작성되며, 각 요구사항이 올바르게 구현되었는지 검증합니다.

## 테스트 시나리오 (TEST SCENARIOS)

### AC-SQL-001-01: 한글 설명 추가 검증

**Given:**
- classicmodels 데이터베이스가 MySQL에 로드되어 있음
- 개선된 car.sql 파일이 존재함

**When:**
- car.sql 파일을 열어서 각 쿼리를 확인할 때

**Then:**
- 모든 쿼리 위에 다음 정보가 한글 주석으로 제공되어야 함:
  - `-- 쿼리 N:` 형식의 제목
  - `-- 목적:` 쿼리의 조회 목적
  - `-- 학습 포인트:` 배울 수 있는 SQL 개념
  - `-- 예상 결과:` 행 수 또는 주요 특징
- UTF-8 인코딩으로 한글이 정상 표시되어야 함

**검증 방법:**
- 텍스트 에디터에서 파일을 열어 주석 형식 확인
- MySQL Workbench에서 파일을 열어 한글 인코딩 확인

**검증 방법:**
- 파일에서 섹션 구분선 검색

### AC-SQL-001-06: 실습 문제 제공 검증

**Given:**

### AC-SQL-001-08: SQL 함수 설명 검증

**Given:**
- car.sql 파일에 SQL 함수 설명 섹션이 존재함

**When:**
- SQL 함수 설명 섹션을 읽을 때

**Then:**
- 다음 함수 카테고리가 포함되어야 함:
  - 집계 함수: COUNT, SUM, AVG, MIN, MAX
  - 문자열 함수: CONCAT, SUBSTRING, UPPER, LOWER
  - 날짜 함수: DATE_FORMAT, YEAR, MONTH, DATEDIFF
  - 조건 함수: IF, CASE WHEN
- 각 함수에 대해 한글 설명과 예제가 제공되어야 함

**검증 방법:**
- SQL 함수 설명 섹션에서 각 함수 이름 검색
- 설명 및 예제 존재 여부 확인
