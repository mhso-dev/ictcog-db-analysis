# MySQL 쿼리 학습 가이드 개발 - 구현 계획

**@PLAN:SQL-001**

## 목표 (OBJECTIVES)

기존 `mysql/01_car/car.sql` 파일을 체계적인 학습 자료로 전환하여 데이터 분석 입문자가 단계별로 MySQL 쿼리를 학습할 수 있도록 개선

## 구현 마일스톤 (MILESTONES)

### Phase 1: 현황 분석 및 분류 (Primary Goal)

**목표:**
- 기존 car.sql 파일의 모든 쿼리를 분석
- 각 쿼리를 난이도별로 분류 (기초/중급/고급)
- 중복 또는 불필요한 쿼리 식별

**산출물:**
- 쿼리 목록 및 난이도 매핑 테이블
- 학습 순서 제안

**의존성:**
- 없음 (독립적 시작 가능)

### Phase 2: 한글 설명 작성 (Primary Goal)

**목표:**
- 각 쿼리에 한글 주석 추가
- 목적, 학습 포인트, 예상 결과 명시
- SQL 함수 설명 섹션 작성

**산출물:**
- 주석이 추가된 car.sql 파일 (버전 1.0)

**의존성:**
- Phase 1 완료 (난이도 분류 필요)

### Phase 3: 실습 문제 개발 (Secondary Goal)

**목표:**
- 각 난이도별 3-5개 실습 문제 작성
- 정답 쿼리 및 힌트 제공
- 예상 결과 검증

**산출물:**
- 실습 문제 섹션 (car.sql 하단)
- 정답 쿼리 (주석 처리)

**의존성:**
- Phase 2 완료 (학습 내용 기반 문제 출제)

### Phase 4: 검증 및 문서화 (Final Goal)

**목표:**
- 모든 쿼리 실행 테스트
- 한글 설명 검토 및 교정
- 사용 가이드 문서 작성

**산출물:**
- 테스트 완료된 car.sql (최종 버전)
- README 또는 사용 가이드 문서

**의존성:**
- Phase 3 완료 (전체 내용 검증)

## 기술 접근 방식 (TECHNICAL APPROACH)

### 1. 쿼리 분류 기준

**기초 (Basic):**
- SELECT, FROM, WHERE
- ORDER BY, LIMIT
- 단일 테이블 조회
- 기본 집계 함수 (COUNT, SUM)

**중급 (Intermediate):**
- INNER JOIN, LEFT JOIN
- GROUP BY, HAVING
- 단순 서브쿼리 (WHERE IN)
- CASE WHEN 조건문

**고급 (Advanced):**
- 다중 JOIN (3개 이상 테이블)
- 상관 서브쿼리
- 윈도우 함수 (ROW_NUMBER, RANK)
- CTE (WITH 절)

### 2. 주석 작성 가이드

**일관된 형식:**
```sql
-- 쿼리 N: [제목]
-- 목적: [조회 목적]
-- 학습 포인트: [배울 개념]
-- 예상 결과: [행 수 또는 특징]
```

**명확한 설명:**
- 1-2문장으로 간결하게
- 기술 용어는 한글로 번역 (예: "집계" 대신 "그룹화 후 합계")
- 실무 활용 사례 포함

### 3. 실습 문제 설계 원칙

**점진적 난이도:**
- 기초: 선행 예제 1-2개 조합
- 중급: 새로운 조건 추가
- 고급: 복합적 분석 요구

**즉시 피드백:**
- 정답 쿼리는 주석으로 제공
- 학습자가 주석 해제하여 비교

**실무 연관성:**
- "상위 10명 고객 찾기"
- "월별 매출 집계"
- "재고 부족 상품 리스트"

## 위험 요소 및 대응 (RISKS AND MITIGATION)

### 위험 1: 기존 쿼리의 오류 발견
**대응:**
- Phase 1에서 모든 쿼리를 실제 실행하여 검증
- 오류 쿼리는 수정 또는 제거
- 변경 사항은 주석에 명시

### 위험 2: 난이도 분류의 주관성
**대응:**
- 명확한 분류 기준 문서화 (위 "기술 접근 방식" 참조)
- 학습자 피드백을 통한 재분류 가능성 열어둠
- 쿼리 복잡도를 객관적 지표로 측정 (JOIN 수, 서브쿼리 깊이)

### 위험 3: 한글 인코딩 문제
**대응:**
- UTF-8 인코딩 명시
- MySQL Workbench 및 CLI에서 테스트
- 필요 시 SET NAMES utf8mb4 추가

### 위험 4: 실습 문제의 난이도 불균형
**대응:**
- 각 난이도별 최소 3개 문제 확보
- 선행 학습 내용으로 해결 가능한지 검증
- 힌트 단계별 제공 (1단계 힌트 → 2단계 힌트 → 정답)

### 테스트 방법
1. **구문 테스트:** 모든 쿼리를 MySQL에서 실행
2. **가독성 테스트:** 입문자가 주석 설명을 이해할 수 있는지 확인
3. **완결성 테스트:** 각 난이도에서 필수 SQL 개념이 모두 다뤄지는지 검증
4. **실습 문제 테스트:** 정답 쿼리가 문제 요구사항을 만족하는지 확인
